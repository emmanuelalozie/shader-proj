# shader-proj
THREE.js and shaders practice

## Experiments

- [`sphere-1`](./sphere-1): an animated sphere with click-drag colouring.
- [`sphere-2`](./sphere-2): a noise-displaced sphere with a custom simplex-noise vertex shader, a displacement-based colour blend and a fresnel rim. Click and drag to change the colour.
- [`sphere-3`](./sphere-3): a noise-displaced shader sphere surrounded by a glowing, noise-animated particle field.

## Running an experiment

Each experiment is its own Vite project:

```sh
cd sphere-2
npm install
npm run dev
```
